MathHub.info is a portal for active mathematical documents and an archive for flexiformal mathematics, developed at Friedrich-Alexander-Universität Erlangen-Nürnberg by kwarc group. It offers a rich interface for reading, writing, and interacting with mathematical documents and knowledge, and a rich API interface for knowledge and documents.
