\section{Dataset}
In this thesis, datasets were created to address the identified problems.
\subsection{Content and Learner Profile Dataset}
A dataset used for this thesis is a mixed dataset from multiple sources: MathHub and the Learner Model.
The course materials and the knowledge graph built from them are available on MathHub. Every symbol on MathHub has a URL and associated content.
The Learner Model associates Bloom's Taxonomy levels with every symbol in MathHub.

\subsection{Question dataset}
Another dataset created for this thesis is a list of questions from students in the courses "AI-1/2" and "SMAI".
This dataset contains over 50 questions about these courses and was used to test the model's results.
Some student questions are very general, while others do not pertain to the course materials.
\subsection{Fine-tuning dataset}
\label{fine_tune_dataset}
The RAFT method requires fine-tuning the model, so a dataset was created that focuses on the
research questions. This dataset contains 150 prompts with handcrafted answers.
Each prompt is an actual prompt used in the RAFT system, and the answers focus on
the prerequisites and their varying levels.
In this dataset, some questions cannot be answered from the prompt alone. The reason for this is
to observe whether the model, after fine-tuning, returns a "don't know" answer for these questions.
