\section{Dataset}
In this thesis, datasets were created to address the identified problems.
\subsection{Content and Learner Profile Dataset}
A dataset used for this thesis is a mixed dataset from multiple sources: MathHub and the Learner Model.
The course materials and the knowledge graph built from them are available on MathHub. Every symbol on MathHub has a URL and associated content.
The Learner Model associates Bloom's Taxonomy levels with every symbol in MathHub.
\begin{center}


  \begin{tikzpicture}
    \node (leaner)   [terminal]                        {Learner Model};
    \node (symbols) [terminal,right=of leaner]           {Symbol(Topic)};
    \node (Prerequisites)     [terminal,right=of symbols]         {Prerequisites(symbol)};
    \node (explian) [terminal, above=of symbols] {Explain};
    \node (definition) [terminal, below=of symbols] {Definition};

    \path (leaner)   edge[->]           (symbols)  % simple edges
    (Prerequisites) edge[->]           (symbols)
    (symbols) edge[->] (explian)
    (symbols) edge[->] (definition);

  \end{tikzpicture}
\end{center}
The Tripartite name originates from this part because three separate systems are combined to produce one dataset for the task.
\subsection{Question database}
Another dataset created for this thesis is a list of questions from students in the courses "AI-1/2" and "SMAI".
This dataset has over 70 questions about these courses. It used to test the model and Fine-tune it.
